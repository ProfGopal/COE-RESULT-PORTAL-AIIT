# Release Notes: AIIT Version 8.2

* **Robust Curriculum Editor Loader:** Enhanced `window.loadCurriculumEditor()` and `window.triggerLoadCurriculum()` to render interactive category/course rule cards when "LOAD CURRICULUM" is clicked.
* **Admin Curriculum Controls:** Enabled full interactive credit editing (`adminEditCategoryCredits`), course code additions (`adminAddCourseCode`), and course code removals (`adminRemoveCourseCode`).
* **Faculty Read-Only Curriculum Viewer:** Provided `renderFacultyCurriculumViewer(container)` to render static, read-only curriculum information for faculty members.
