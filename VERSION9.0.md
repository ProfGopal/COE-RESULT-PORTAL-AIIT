# Release Notes: AIIT Version 9.0

* **Student Portal Tabs Restored:** Dynamically injected student tabs ("📚 All Courses", "⚠️ Active Backlogs", "🎓 Degree Audit Check", "📄 Export PDF").
* **Faculty Directory & Filtering Repair:** Fixed search, batch, and program filters in faculty view, updated student count badge, and fixed "View All Students" directory renderer.
* **Admin Curriculum Table Editor:** Rebuilt curriculum manager into an intuitive table layout with interactive category renaming (`adminRenameMainCat`, `adminRenameSubCat`), credit threshold editing (`adminEditMainCreds`, `adminEditSubCreds`), and course code management (`adminAddCourse`, `adminRemoveCourse`).
* **Global PDF Export Utility:** Integrated client-side PDF export feature (`exportStudentPDF()`) utilizing jsPDF autoTable.
